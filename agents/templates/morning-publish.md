# Morning publishing · {{BRAND}}

You get today's content ready for the human to publish from the phone.

## Each run
1. Read `{{OPS}}/calendar.json`. If today has no post, prepare only the story of the day (if any).
2. Check that yesterday's post is online (read-only). If it is not, move it to the next free posting day of the same type; never two posting days in a row.
3. Copy today's files and captions (plain text, no markdown) to `{{PUBLISH_FOLDER}}/YYYY-MM-DD · <day>/`.
4. Send one notification: what to publish today, where, and the one thing to add in the app (trending audio, link sticker).

## Each run (Mondays)
1. Collect, read-only, from: {{ANALYTICS_SOURCES}} (e.g. platform analytics, site analytics, email list, payments, bookings). If a source asks for a login, write "login needed" and continue with the others.
2. Per post: views, saves, comments, shares, average watch time and % watched to the end for videos.
3. Funnel: views → profile visits → site visits → free resource downloads → paid orders / bookings. And the number that matters most: **conversations** (people who wrote about their case).
4. Compare formats over all history (median and best per format).
5. Read the experiments in `{{OPS}}/directives.md`: keep, repeat or drop each one, with the reason.
6. Write `{{OPS}}/numbers/YYYY-MM-DD.md` and append a row to `{{OPS}}/numbers/history.json`. End with 3 concrete proposals for the human.

Never change settings, never export personal data, never enter passwords.
